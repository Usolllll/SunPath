## 4. 功能范围（M1–M11）

用户与权限、成绩与资格、院校与专业库、历年录取数据、院校检索与冲稳保推荐（含 AI 匹配/问答）、志愿表编制与填报（导入/导出/提交撤回）、录取进程与结果查询、政策资讯与站内消息、数据分析与运营看板、系统管理与合规审计、留学规划与官方申请入口。

## 5. 边界与已知缺口

- 系统为教学演示：院校、分数、位次与招生计划均为模拟/示例数据；一分一段为示例数据，上线前须替换为省考试院官方表。
- 不承诺录取概率；冲稳保为规则估算；真实投档数据仅作核对参考。
- 无官方录取结果数据源，结果查询/推送为演示判定。
- 免费公共模型通道约每 45 秒限 1 次；建议演示前切换智谱 GLM-4-Flash 或自备 API Key。
- 未实现/部分实现项详见 RTM「遗留缺口与计划」页。
