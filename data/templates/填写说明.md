# SunPath 真实数据填写说明

按下表中的固定选项填写，直接复制选项文字，**不填选项编号、不自创简称、不加多余空格**。这些是项目统一用词；来源中的不同写法按对应规则转换。没有合适选项时选“其他”，把原文写在备注，不能选一个意思相近但不准确的值。

02 是基础录取表；03 与 02 完全相同，仅增加“选科要求”。两份选一份提交，同一条记录不要重复交。不再收集学费、学制或计划人数，也不需要登记发布日期和采集人员。

对照文件：[真实样例 CSV](../examples/02_历年录取数据_填写样例.csv)、[样例说明](../examples/样例说明.md)。

## 先确定一行代表什么

**一行只对应一所学校、一个生源省份、一个年份、一个科类、一种招生范围、一次投档，以及一个官方公布的专业、专业类或专业组记录。** 这些单值不能在同一格拼成多个。

- 官方公布招生组或大类及所含专业：“专业组名称”填组或大类名称，“具体专业”填公布的专业列表，用中文分号 `；` 连接，保留一行。
- 官方只公布组或大类名称，没有细分专业：“专业组名称”和“具体专业”都填该名称，不猜测成员专业。
- 官方单独公布一个具体专业：如有上级组名则填写组名；没有则两列都填该专业名称。
- 官方只公布学校整体数据：两列都留空，备注选“学校整体数据”。

本模板的“专业组名称”是项目用于归类的招生组或专业类名称，**不保证是省考试院官方设置的院校专业组**。来源只有专业类时允许用类名填充，但“专业组代号”仍留空；备注选“专业组名称按专业类填充”，不能编造官方组号。

生源省份是考生参加录取的省份，不是学校所在地。不同省份、年份或专业的数据分行记录，不能把分数、位次分别从不同记录拼接。

## 可以直接做选择题的字段

表中的 `、` 用于列出可选项，不要把它一起复制进单元格。

| 字段     | 固定选项                                                                                                                                                                                     | 选择规则                                                                                                                                                                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 生源省份 | 北京、天津、河北、山西、内蒙古、辽宁、吉林、黑龙江、上海、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广东、广西、海南、重庆、四川、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆 | **单选**。统一写“浙江”，不写“浙江省”；写“内蒙古”，不写“内蒙”。本轮先采集大陆普通高考招生数据，其他招生体系暂不混入                                                                                                                                                       |
| 招生年份 | 2023、2024、2025、2026                                                                                                                                                                       | **单选**，按数据所属招生年份选，不按公告发布日期选。更早年份先与负责汇总的同学确认，统一增加选项                                                                                                                                                                         |
| 招考科类 | 综合改革、物理类、历史类、理工、文史、艺术类、体育类、其他                                                                                                                                   | **单选**。浙江、上海、山东、海南、北京、天津的普通类综合改革记录统一选“综合改革”；来源“首选物理/物理科目组”选“物理类”，“首选历史/历史科目组”选“历史类”，“理科”选“理工”，“文科”选“文史”。按该省该年的制度和来源判断，不能把物理类与理工混为一类；不确定选“其他”并备注原文 |
| 招生类型 | 普通类、国家专项、地方专项、高校专项、民族专项、中外合作办学、定向、公费师范、预科、其他                                                                                                     | **可多选**。原文“普通类平行录取/普通批普通招生”统一选“普通类”。有明确专项或项目标签时选对应项；同一项目同时适用两个标签时用中文分号 `；` 连接，顺序按本行选项从左到右。例如 `普通类；中外合作办学`。不要把两条独立招生记录合成多选标签                                   |
| 投档轮次 | 首次投档、再次投档、征集志愿、补录、未注明                                                                                                                                                   | **单选**。官方明确为首轮平行投档的选“首次投档”；明确为再次投档、征集或补录的分别选对应项。不能因为出现“第二段”就自动选“再次投档”。无法确认选“未注明”                                                                                                                     |

“艺术类”“体育类”“其他”等数据可以单独收集，但不要与普通类数据合并比较位次。优先完成本组约定的普通类范围。

## 必须照官方资料填写的字段

学校、专业名称和录取数字不能事先编成有限选项。这些字段按下列格式照录，不自己改名、不推算缺失数值。

| 字段         | 单选/单值还是多值 | 统一填写方法                                                                                                                                                |
| ------------ | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 学校名称     | 单值              | 官方全称，例如“浙江工业大学”，不写“浙工大”。同一学校全组统一使用同一全称，曾用名可写备注                                                                    |
| 全国院校代码 | 单值              | 教育部全国院校代码，按文本保存。不是省内招生院校代号；不知道留空，不自行截取学校标识码推算                                                                  |
| 专业组代号   | 单值              | 有则按原文填写，保留前导零、字母；一行只填一个组代号。没有或未公开留空，不填“无”“不限”“0”                                                                   |
| 专业组名称   | 单值              | 填招生组或专业大类的名称，例如“电子信息”。只有一个专业且没有组名时填该专业名称；仅学校整体记录留空。与“专业组代号”分别填写，不将代号与名称拼在同一格        |
| 具体专业     | 可多值            | 来源明确列出组内多个专业时，按原顺序用中文分号 `；` 连接，例如 `计算机；软件工程；电气`。只有组或大类名称时，与“专业组名称”填同一名称；没有细分专业不能猜测 |
| 最低分       | 一个数字          | 必填，如 `628`；有小数如实保留，用英文小数点 `.`，不加“分”。没有官方数字的资料暂不当作完整录取记录提交                                                      |
| 最低位次     | 单值              | 来源公开则照录，如 `25010`；若官方位次号带字母、前导零则以文本完整保留。不写 `25,010`，不写“第25010名”。查不到留空，不能按分数估算                          |
| 最高分       | 一个数字或留空    | 官方未公开就留空，不用最低分补齐                                                                                                                            |
| 平均分       | 一个数字或留空    | 官方未公开就留空，不自己对其他数字求平均                                                                                                                    |
| 实际录取人数 | 一个整数或留空    | 只填官方实际人数，不写“人”。来源只有计划数时留空，不能把计划数复制进来                                                                                      |
| 来源链接     | 可多值            | 必填，具体官方公告、查询结果或附件的完整网址；多条链接之间用中文分号 `；`，保持原网址不变。不要只写官网首页                                                 |
| 备注         | 可多值            | 优先复制后文的固定标签；多个标签用中文分号 `；`。有无法靠选项表达的信息时，允许在标签后补原文                                                               |

同一组内专业名称逐年变化时，保留当年的官方名称，不为了名称一致而修改历史事实。跨年对应关系后续再整理。

## “专业组名称”和“具体专业”的填写对照

| 官方资料的情况                                               | 专业组名称          | 具体专业                         | 怎么处理分数                                     |
| ------------------------------------------------------------ | ------------------- | -------------------------------- | ------------------------------------------------ |
| `电子信息（计算机、软件工程、电气）`，只公布这一组共同的数字 | `电子信息`          | `计算机；软件工程；电气`         | 一行记录该组数字，不拆成三行复制最低分           |
| 只公布 `电子信息`，没有细分专业                              | `电子信息`          | `电子信息`                       | 保留原记录；备注选“未公布细分专业”               |
| `计算机类（含计算机科学与技术、软件工程）`，只公布该类数字   | `计算机类`          | `计算机科学与技术；软件工程`     | 保留一行，备注选“专业类数据”，并保留完整原始名称 |
| 只公布 `计算机类`，没有细分专业                              | `计算机类`          | `计算机类`                       | 不猜测它包含哪些具体专业                         |
| `电子信息` 组下各专业分别公布自己的分数                      | 每行都填 `电子信息` | 每行只填对应的一个专业名称       | 各专业分行，使用各自数字                         |
| 单独公布 `软件工程`，没有组或大类名称                        | `软件工程`          | `软件工程`                       | 记录该专业自己的数字                             |
| 官方合并统计多个专业，没有组或大类名称                       | 留空                | 用 `；` 连接官方公布的完整专业名 | 保留一行；备注选“多专业合并统计”                 |

上表是格式示意，不代表某校真实的专业设置。“计算机”“电气”等仅用于展示你的填写方式；实际收集时使用官方完整专业名称，不自行缩写。不要用 `/`、英文逗号或顿号连接“具体专业”中的多个独立名称。

带有“含某某专业”的名单可以拆成“具体专业”列表；“中外合作办学”“师范”“实验班”“培养方向”等限定不是多个专业，不能按括号直接拆分，要保留在对应名称中。整理过原始名称时，在备注写 `原始名称=官方完整原文`。

**具体专业列可以是一个专业列表，但最低分、位次、人数仍只描述该行的官方统计对象。** 不能把一个专业组或专业类的数字当作列表中每个专业各自的录取结果。

## 03 表的“选科要求”：从固定选项中选一个

| 固定选项   | 什么情况下选择                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 不限       | 官方明确写“不限/不提科目要求”                                                                  |
| 物理       | 官方只要求必须选物理                                                                           |
| 历史       | 官方只要求必须选历史                                                                           |
| 物理且化学 | 物理和化学两门都必须选                                                                         |
| 物理且生物 | 物理和生物两门都必须选                                                                         |
| 化学且生物 | 化学和生物两门都必须选                                                                         |
| 其他       | 其他单科、三科组合、“任选一门”、包含技术科目或更复杂的组合；备注写 `原始选科要求=官方完整原文` |
| 未公开     | 没有找到该省、该年、该专业或专业组的官方选科要求                                               |

例如，原文“物理、化学（2门科目考生均须选考方可报考）”统一选 `物理且化学`；原文“物理、化学、生物任选一门”必须选 `其他` 并在备注保留原文，不能改成三门都要选。

**选科要求只选一个完整选项，不用 `；` 把科目连起来。** `物理；化学` 无法表达“且”还是“或”，禁止这样填写。填“其他”时必须带原文，填“未公开”不能当成“不限”。

选科要求必须与录取记录的生源省份、年份及专业一致。可以从同年官方招生计划中找要求，但不用抄录学费、学制和计划人数。

## 备注也尽量选标签

按实际情况复制，可多选，用中文分号 `；` 连接。没有适用情况可以留空；不需要为了凑标签写一大段说明。

| 用途                                 | 固定标签或格式                                                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| 说明数字对应什么                     | `学校整体数据`、`专业组数据`、`专业数据`、`专业类数据`、`多专业合并统计` 中选一个                                               |
| 区分投档与最终录取                   | `投档数据`、`最终录取数据`、`数据性质待确认` 中选一个                                                                           |
| 缺失数值                             | `未公开最低位次`、`未公开最高分`、`未公开平均分`、`未公开实际录取人数`，可多选                                                  |
| 来源只有计划数                       | `原表仅提供计划数`，不把计划数填进实际录取人数                                                                                  |
| 只有组名或专业类名、没有细分专业     | `未公布细分专业`                                                                                                                |
| 用类名或单个专业名填充专业组名称     | `专业组名称按专业类填充` 或 `专业组名称按单个专业填充`                                                                          |
| 不确定或冲突                         | `来源冲突待确认`；必要时补 `差异=具体差异`                                                                                      |
| 固定选项选了“其他”                   | 对应写 `原始科类=原文`、`原始招生类型=原文` 或 `原始选科要求=原文`                                                              |
| 需要定位附件或保留原始名称及其他细节 | 可补 `来源1位置=工作表及行号`、`来源2用途=全国院校代码`、`原始名称=完整原文`、`原始批次=原文`、`原始校区=原文`、`原始轮次=原文` |

例如：`专业类数据；投档数据；未公开最高分；未公开平均分；未公开实际录取人数；原表仅提供计划数`。

同校同年存在不同校区、批次或数据范围时，不要合并取最低值；分行保留并在备注写明区别。相关字段虽已精简，原始数据的差别仍需保留。

## 分隔符和空值统一规则

| 情况                             | 统一规则                                                                                                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 同一格内多个独立值               | 一律用中文分号 `；`，例如多个具体专业、两个来源网址、多个招生类型标签、多个备注标签；分号前后不加空格、不换行                                                                |
| 一个字段名同时提到两个概念       | 先看 CSV 是否已有两列。例如“专业组代号”和“专业组名称”是两列，各填各的，不用分号合并                                                                                          |
| 单值字段出现多个值               | 学校、省份、年份、科类、轮次、组代号、分数和位次都不可多选；分别建行                                                                                                         |
| 官方名称、网址及备注中的引用原文 | 明确列出的成员专业名单按上表拆成 `；` 列表；单个专业的方向、合作办学等限定及网址内部标点保留。备注中的引用原文本身含中文分号时，保留在备注末尾，后续人工核对，不自动拆解原文 |
| 数值或代码未公开                 | 空白，不能填 `0`、`-`、`无`、`N/A`、`未公开`；可在备注选择对应缺失标签。官方真的公布为 0 才填 0                                                                              |
| 选择字段未确认                   | 轮次选“未注明”；选科要求选“未公开”；科类/招生类型不能确认时选“其他”并备注原文，不猜测                                                                                        |
| CSV 的列分隔符                   | 仍是英文逗号 `,`，由 Excel/WPS 保存 CSV 时处理；不要手工替换成中文分号                                                                                                       |

## 保存和提交

1. 用 Excel/WPS“数据 → 从文本/CSV”打开，编码选 UTF-8，列分隔符选英文逗号。院校代码、专业组代号和位次号列选“文本”，保留前导零和字母。
2. 不改表头、不加新列、不插入合计行，不合并单元格。CSV 模板本身没有下拉菜单，需从本说明复制选项文字。
3. 保存为“CSV UTF-8（逗号分隔）”。文件可命名 `02_浙江_2025_姓名.csv` 或 `03_浙江_2025_姓名.csv`。
4. 提交前检查：固定选项文字一致；多值用 `；`；每行数字来自同一条官方记录；未公开数值留空；“其他”附原文；链接能定位来源。
5. 先每人交 5–10 条核对，再批量收集。建议优先采集一个生源省份的 2023–2025 年资料；2026 年结果可另行收集，但不能用于模拟 2026 年报考时的历史依据。

## 来源与后续入库

优先使用省级教育考试院、高校招生官网、教育部的具体页面或附件，不以 AI 回答、搜索摘要或无出处转载作依据。

- [浙江省教育考试院：2025 年高考招生志愿填报百问百答](https://www.zjzs.net/art/2025/6/16/art_45_11314.html)：用于了解查询渠道，不能替代每条记录的具体出处。
- [样例使用的浙江省 2025 年普通类第一段投档表公告](https://www.zjzs.net/art/2025/7/21/art_155_11451.html)：附件中的数字与官方原名照录，固定分类字段按本说明统一。

这些是采集模板，不是当前数据库的直接导入格式。后续需核对专业与专业组对应关系及备注中的差异，再整理入库；本次没有改动开发数据库或推荐算法。
