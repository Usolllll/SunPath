# 历年录取数据填写样例

本目录的 `02_历年录取数据_填写样例.csv` 使用与空白模板完全相同的列，填写一条真实记录，供组员对照。空白模板仍在 `data/templates`，未加入样例。

| 项目 | 样例内容 |
| --- | --- |
| 学校 | 浙江工业大学 |
| 全国院校代码 | 10337 |
| 生源省份、年份 | 浙江、2025 年 |
| 专业组名称 | 计算机类 |
| 具体专业 | 计算机类 |
| 招考科类 | 综合改革 |
| 招生类型、投档轮次 | 普通类、首次投档 |
| 最低分 | 628 |
| 最低位次 | 25010 |
| 最高分、平均分、实际录取人数 | 原表未提供，留空 |
| 专业组代号 | 本来源没有官方专业组代号，留空；不将省内招生专业代号当作组号 |

分数和位次取自[浙江省教育考试院官方公告](https://www.zjzs.net/art/2025/7/21/art_155_11451.html)所附《浙江省2025年普通高校招生普通类第一段平行投档分数线表.xls》，工作表 `tdx2025` 第 52 行。原表该行名称为“浙江工业大学—计算机类”，计划数 224、分数线 628、位次 25010。**224 是计划数，不是实际录取人数，因此没有填进录取人数列。**

全国院校代码依据[浙江工业大学本科生招生专业目录（国标码10337）](https://zs.zjut.edu.cn/html/n2027.html)。两个来源链接都保存在 CSV 的“来源链接”中，备注说明各自支持哪些字段。

这条记录的 628 分是该轮投档最低分，不能当作最终专业录取最低分。由于模板已精简掉单独的口径字段，区别写在“备注”里。不要为了填满所有格子，把未公布的数据补成 0 或从其他年份复制。

分类字段按[填写说明](../templates/填写说明.md)的项目固定选项统一：浙江普通类记录的科类填“综合改革”，招生类型填“普通类”，该条首轮平行投档填“首次投档”；来源中的“普通类第一段平行投档”保留在备注。学校、专业原名和分数、位次保持官方数据不变。

备注使用中文分号 `；` 分隔固定标签，例如 `专业类数据；投档数据；未公开最高分；未公开平均分；未公开实际录取人数`。来源链接有两条，同样用 `；` 分隔。本来源只写“计算机类”，未列出细分专业，因此按新规则，“专业组名称”和“具体专业”两列都填“计算机类”。这只是项目的归类方式，不表示已查到官方院校专业组；备注已注明“未公布细分专业”“专业组名称按专业类填充”。

若官方资料写的是“电子信息（计算机、软件工程、电气）”，填写方式为：专业组名称 `电子信息`，具体专业 `计算机；软件工程；电气`。该句仅示意格式，不是为浙江工业大学新增专业成员；本样例的最低分和位次仍是“计算机类”整体的投档数据。
